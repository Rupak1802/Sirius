# MASTER UI/UX DESIGN PROMPT — MITRA

Design and build a complete, polished, responsive fintech web application called **MITRA**.

## PRODUCT NAME

**Mitra**

### Tagline
**Your financial co-pilot for irregular income.**

### Core idea

Mitra is a financial resilience platform designed specifically for **gig workers and informal workers whose income changes from week to week**.

The product should not feel like a traditional banking dashboard.

It should feel like a **smart financial companion** that continuously understands the user's income, predicts financial stress, recommends savings, protects essential work-related expenses, helps manage multiple income sources, and provides responsible emergency support.

The UI should communicate:

> **“Your income changes. Your financial plan should change with it.”**

The target user is a delivery rider / cab driver / freelancer who does not receive a predictable monthly salary.

Use realistic Indian financial examples and INR currency throughout the product.

---

# 1. DESIGN PHILOSOPHY

Create a design that is:

- Modern
- Premium
- Trustworthy
- Human
- Simple
- Financially intelligent
- Mobile-first but excellent on desktop
- Visually impressive for a hackathon demo
- Extremely easy to understand

Avoid making it look like an accounting application.

Avoid overly complicated charts.

Avoid excessive tables.

Avoid generic corporate banking aesthetics.

The experience should feel like:

**modern fintech + personal finance coach + intelligent assistant**

The visual language should communicate **calm, safety and confidence**, not financial anxiety.

# 7. AI PERSONALIZATION

Do not make the AI feel like a generic chatbot.

It should use the user's financial context.

Every recommendation should answer:

### What?

What should the user do?

### Why?

Why is Mitra suggesting it?

### What happens next?

What will change if the user follows it?

Example:

> **Save ₹350**
>
> You earned 14% more than usual this week.
>
> Saving ₹350 still leaves enough for your upcoming essentials.
>
> After saving, you'll have ₹1,450 available for flexible spending.

The application must tell one coherent story:

### **EARN → UNDERSTAND → PLAN → SAVE → PROTECT → PREDICT → PREPARE → RECOVER**

The entire product should feel like one intelligent system rather than a collection of features.

Do not build a generic banking dashboard.

Build something that makes the user feel:

> **“Mitra understands that my income is unpredictable and adjusts my financial plan around my life.”**

The final UI should look polished enough to be presented to:

- Banks
- Fintech investors
- Hackathon judges
- Gig platforms
- Real users

Prioritize **clarity, visual hierarchy, personalization, trust and demo impact** over unnecessary complexity.

The final result should look like a real product that could launch tomorrow.
